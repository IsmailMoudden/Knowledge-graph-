# MOI — Knowledge graph

Interactive MOI knowledge graph and platform demonstration.

**Live demo:** https://ismailmoudden.github.io/Knowledge-graph-/

Open `index.html` locally, or use the live demo. No installation or build step is required.

- **Play** presents the MOI architecture.
- **Go further** opens the broader platform and its guided scenario.
- GitHub Pages serves the repository root from the `main` branch.
